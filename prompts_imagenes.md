# Etapa 2 — Prompts de texto-imagen (Aptia)

Estos tres prompts se ejecutaron manualmente en **NightCafe Studio** (https://creator.nightcafe.studio), una herramienta gratuita de generación de imágenes, ya que DALL·E dejó de ofrecer acceso gratuito por API. No hay integración por código en esta etapa: el prompt se escribe directamente en la herramienta y la imagen resultante se guarda en la carpeta `/imagenes` de este repositorio.

---

## Prompt 4 — Logo de la marca

**Objetivo:** generar el logotipo de Aptia.

```
Diseña un logotipo minimalista para una app llamada "Aptia", dedicada a ayudar a motociclistas
a encontrar repuestos compatibles para sus motos. Estilo: flat design, moderno, líneas limpias,
sin texto en la imagen (solo el ícono). Debe combinar de forma sutil la idea de
"encaje/compatibilidad" (por ejemplo dos piezas que calzan perfectamente, como un engranaje o
dos formas que se complementan) con un elemento reconocible de motocicleta (una rueda o un
manubrio estilizado). Paleta de colores: azul marino, verde azulado (teal) y un acento dorado.
Fondo blanco o transparente. Formato cuadrado, apto para ícono de app.
```

## Prompt 5 — Mockup de pantalla principal de la app

**Objetivo:** generar un mockup visual de la interfaz para presentaciones y validación.

```
Genera la imagen de la pantalla de inicio de una aplicación móvil llamada Aptia, dentro del
marco de un teléfono celular moderno. La pantalla debe mostrar: una barra de búsqueda en la
parte superior con el texto "¿Qué repuesto necesitas?", tres tarjetas debajo representando
categorías (Frenos, Aceite y filtros, Llantas) con íconos simples, y una franja inferior de
navegación con 4 íconos (Inicio, Buscar, Mi moto, Perfil). Estilo de interfaz limpio tipo app
fintech colombiana (inspirado en apps como Nequi o Rappi), colores azul marino, teal y dorado,
tipografía sans-serif moderna, alto contraste y legibilidad.
```

## Prompt 6 — Pieza publicitaria para talleres y marcas aliadas

**Objetivo:** generar una pieza de marketing para el futuro programa de pauta.

```
Diseña una pieza publicitaria cuadrada (formato red social) para promocionar la alianza entre
un taller de motos local y la app Aptia. Debe incluir de forma visual (sin texto legible, solo
composición gráfica): una motocicleta estilizada de perfil, un ícono de ubicación/pin como si
señalara un taller cercano, y elementos gráficos que sugieran confianza y recomendación (como
una estrella o un check). Estilo ilustrado, plano, colores corporativos de Aptia (azul marino,
teal, dorado), ambientado sutilmente con elementos que evoquen el Caribe colombiano (luz cálida,
paleta cálida de fondo).
```
